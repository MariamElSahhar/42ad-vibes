# 🗓️ 42 Abu Dhabi Vibes

An event management platform with public and admin views. Developed for the Frontend Faceoff Qualifiers.

## ✨ Features

-   🔍 Public event listing
-   🔐 Admin dashboard with event CRUD
-   🧠 Supabase role-based access
-	🎫 Event RSVP and cancellation

## 🧰 Tech Stack

-   **Next.js 15** (App Router)
-   **TypeScript**
-   **Tailwind CSS**
-   **Supabase** (auth, database, RLS)
-   **Lucide Icons**
